# Beyond Muhammad Saad — Skills

A collection of 20 free, universal, tested skills for creators and operators — by **Muhammad Saad Ranjha (Beyond Muhammad Saad)**.

Every skill in this collection was verified end to end, compared against the best existing skills for the same job, upgraded to be the sharpest version anywhere, and tested on a real case before publishing. No claim in any skill is stated as fact unless it was checked against a real source or a real run; anything unverified is cut or clearly marked.

## Install / use

Each skill is one folder with a `SKILL.md` file. Copy any folder into your agent's skills directory (for example `~/.claude/skills/` or your project's skills folder) and invoke it by name. No dependencies beyond what each skill states in its own setup section.

```bash
git clone https://github.com/JokerHTML/beyond-muhammad-saad-skills.git
cp -r beyond-muhammad-saad-skills/youtube-shorts-seo ~/.claude/skills/
```

## How these skills were built

1. **Audit** — every source skill read in full; skills doing the same single job merged into one (viral-seo + description-writing + post-writing-seo became `youtube-shorts-seo`).
2. **Wide search** — for each skill, the best existing versions were found across web search, YouTube, all major skill directories (Skills Directory, askill.sh, Skillstore, skills.sh, claudepluginhub.com, skillsllm.com), GitHub, PyPI/npm, official docs, and top creators' published workflows — and compared feature by feature.
3. **Truth gate** — every claim, number, stat, command, path, tool name, example, and promised result verified against a real source or a real run. Anything unverifiable was cut or marked unverified — never stated as fact.
4. **Testing gate** — each skill's workflow was run end to end (or its key commands and steps) on a real test case before it was cleared. A skill that failed testing was fixed and re-tested green.
5. **Universal** — no brand names, account IDs, channel names, or internal URLs. Methods, checklists, and worked examples are generic; placeholders mark where your own values go.
